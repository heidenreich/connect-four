# Connect Four

Two-player, pass-and-play Connect Four for one phone.

Tap a column to drop a disc, then hand the phone over. First to line up four in a row (across, down or diagonal) wins.

## Features

- Editable player names
- Running scoreboard (wins and draws), saved in the browser
- Undo the last move
- Players alternate who goes first each game
- Light and dark themes, works at phone width
- Keyboard: press 1–7 to drop in a column

## Play

It's a single file with no build step. Open `index.html` in any browser.

To get a link you can open on any phone, turn on GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
